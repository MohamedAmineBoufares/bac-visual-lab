# Security

Bac Visual Lab runs entirely in the browser: no server, no accounts, and settings and progress stay in
the browser's `localStorage`.

If you find a security problem (for example a way to run scripts through lesson content), please
**do not open a public issue**. Report it privately from the repository's
[Security tab](https://github.com/MohamedAmineBoufares/bac-visual-lab/security/advisories/new). You'll
get an answer as soon as possible, and credit in the fix if you want it.
